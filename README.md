# Float App

Float is an intelligent cash flow forecasting and runway management platform designed for modern founders, finance operators, and high-growth companies.

---

## 🚀 Frontend

The frontend is built with **React**, **Vite**, and **Lucide Icons**, featuring a high-converting, interactive landing page.

### Features
- **Hero Section**: Live treasury dashboard preview with scenario modeling (Conservative, Base Case, Aggressive).
- **Interactive Runway & Buffer Calculator**: Live sliders for cash balance, monthly revenue, and monthly burn with real-time runway and net burn metrics.
- **Feature Showcase**: Real-time sync, multi-scenario sandboxes, buffer early warnings, and bank-grade security.
- **Transparent Pricing**: Monthly/annual toggle with dynamic pricing cards.
- **Customer Testimonials & Social Proof**: Verified reviews and enterprise logos.
- **Interactive FAQ Accordion**: Expandable Q&A section.
- **Interactive Onboarding Modal**: Full sign-up, demo booking, and sign-in tabs with instant validation.

---

### Getting Started

```bash
cd frontend

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
